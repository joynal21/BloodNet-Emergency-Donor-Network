# BloodNet V4

BloodNet V4 is an advanced emergency blood and donor network demo project built with PHP, MySQL, HTML, CSS and JavaScript.

## V4 highlights
- Dynamic homepage slideshow
- Community events / blood camps section
- Inspiring stories from doctors, donors and patient families
- Admin content manager for hero text, media, events and stories
- Emergency request workflow with history tracking
- Localhost-only demo login shortcuts

## Install
- Put the `emergency_blood_network_v4` folder into `C:\xampp\htdocs\`
- Start Apache and MySQL
- Import `database.sql` for a fresh install
- If you already use a previous version, import `upgrade_v4.sql`
- Visit `http://localhost/emergency_blood_network_v4/`
